# PhotoEdit

เว็บแต่งรูปออนไลน์ธีมอวกาศ สร้างด้วย HTML, CSS และ JavaScript ประมวลผลรูปในเครื่องผู้ใช้ ใช้งานได้ฟรีโดยไม่ต้องสมัครสมาชิก พร้อม 200 สไตล์ 40 เอฟเฟกต์ 18 ตัวปรับแสงและสี 32 กรอบ 80 สติ๊กเกอร์วาด และอีโมจิ 3,714 แบบรวมรุ่นสีผิว ค้นหาและโหลดจากไฟล์ในเว็บโดยตรง

## โครงสร้างโปรเจกต์

```
index.html                  หน้าแรก
editor.html                 หน้าสตูดิโอแต่งรูป
assets/                     ฟอนต์ ไอคอน รูปตัวอย่าง และไฟล์สัญญาอนุญาต
src/
  styles/                   สไตล์แยกตามส่วน โหลดตามลำดับใน HTML
    base.css                ฟอนต์ ตัวแปรสี และรีเซ็ตพื้นฐาน
    components.css          ปุ่ม แบรนด์ และพื้นหลังอวกาศ
    home.css                ฮีโร่และเนื้อหาหน้าแรก
    dialogs.css             หน้าต่างสนทนาและการแจ้งเตือน
    editor.css              โครงหน้าและพื้นที่ทำงานของสตูดิโอ
    inspector.css           แผงเครื่องมือ ฟอร์ม และตัวเลือกทั้งหมด
    motion.css              แอนิเมชันเปลี่ยนหน้าและแผง
    responsive.css          สื่อ querie สำหรับหน้าจอขนาดต่าง ๆ
    refinements.css         ปรับแต่งละเอียดของส่วนติดต่อผู้ใช้
    panels.css              รายละเอียดแผงเครื่องมือและอีโมจิ
  js/
    core/
      presets.js            หมวดหมู่และพรีเซ็ต 200 สไตล์
      fonts.js              รายการฟอนต์และตัวโหลดฟอนต์
      ui.js                 การเข้าถึง กล่องสนทนา และการเปลี่ยนหน้า
      data/emoji.js         ข้อมูลอีโมจิที่สร้างจากสคริปต์
    engine/                 เครื่องมือประมวลผลภาพ
      index.js              รวม export ของเอนจิน
      constants.js          ขีดจำกัดไฟล์และรายการกรอบ/สติ๊กเกอร์
      state.js              สถานะเริ่มต้นของภาพ
      geometry.js           ครอป หมุน จัดแนว และขนาดส่งออก
      effects.js            ปรับแสงสีและเอฟเฟกต์
      draw.js               รูปดาวและหัวใจที่ใช้ร่วมกัน
      stickers.js           วาดสติ๊กเกอร์และเส้นวาด
      frames.js             สร้างกรอบรูปทุกแบบ
      render.js             ประกอบภาพและวาดพรีวิว
      files.js              อ่านไฟล์ ตรวจขนาด และสร้างไฟล์ส่งออก
    pages/
      home.js               สคริปต์หน้าแรก
      editor/
        index.js            จุดเริ่มต้นของสตูดิโอ
        dom.js              ตัวช่วยเลือก element และไอคอน
        labels.js           ข้อความป้ายกำกับเครื่องมือ
        store.js            สถานะกลาง ประวัติย้อนกลับ และการแจ้งเตือน
        canvas.js           พรีวิว ซูม ครอป และการลากบนรูป
        upload.js           เปิดรูป ลากวาง และวางจากคลิปบอร์ด
        export.js           หน้าต่างดาวน์โหลดและสร้างไฟล์
        dialogs.js          กล่องยืนยันและปิดหน้าต่าง
        actions.js          ปุ่มรีเซ็ต เครื่องมือ และการซูม
        shortcuts.js        คีย์ลัด
        panels/             แผงเครื่องมือแยกตามหมวด
scripts/                    สคริปต์สำหรับพัฒนาและสร้างข้อมูล
  serve.mjs                 เซิร์ฟเวอร์ static ขนาดเล็ก
  build-emoji-data.mjs      สร้าง src/js/core/data/emoji.js
  screenshots.mjs           สร้างภาพตัวอย่างใน docs/screenshots
```

## คำสั่งที่ใช้

```bash
npm start          # เปิดเว็บที่ http://127.0.0.1:3000
npm run screenshots
```
